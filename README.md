# ookla-bps-geospasial

Data atribut tabular per provinsi (34 provinsi, kode BPS) untuk tugas Visualisasi Data Geospasial.

| Kolom | Keterangan | Sumber |
|---|---|---|
| `kode_prov` | Kode provinsi BPS (dipakai sebagai kunci merge dengan GADM `CC_1`) | BPS |
| `pct_akses_internet` | % penduduk usia 5+ yang pernah mengakses internet dalam 3 bulan terakhir (Perkotaan+Perdesaan), 2022 | [BPS](https://www.bps.go.id/id/statistics-table/2/NDA2IzI=/persentase-penduduk-usia-5-tahun-ke-atas-yang-pernah-mengakses-internet-dalam-3-bulan-terakhir-menurut-provinsi-dan-klasifikasi-daerah.html) |
| `kepadatan_penduduk` | Kepadatan penduduk (jiwa/km²), 2021 | [BPS](https://www.bps.go.id/id/statistics-table/2/MTQxIzI=/kepadatan-penduduk-menurut-provinsi.html) |
| `pct_penduduk_miskin` | % penduduk miskin (P0), Jumlah, September 2022 | [BPS](https://www.bps.go.id/id/statistics-table/2/MTkyIzI=/persentase-penduduk-miskin--p0--menurut-provinsi-dan-daerah.html) |

Data bersumber dari Badan Pusat Statistik (bps.go.id).
